How it works

  1. Code computes every number, ranks every center and metric, and labels every plan.
  2. The model writes 16 short passages from placeholders. It never sees a digit.
  3. A validator rejects any digit not in the facts file, any banned word, and any restated line.
  4. A person approves the run. The approved run is what you are reading.
  5. What a Monday costs: $0.26 in model calls for this run ($0.2640 exact), at list price.
  6. To check any number: open Show all the detail and click its E number. The appendix names the file, the column, the center and the week.
  7. To rerun the numbers: python -m src.run --stage digest --cached, from the repo, no API key. To rewrite the words, drop --cached; this run cost $0.26. A test suite runs before every commit.
  8. What it needs each week: the four CSVs. Four leaders for a year at this run's rate: about $55 in model calls.

The repository holds the pipeline, the prompts, the tests, the data generator and every output: github.com/stevon-squadtrip/ops-digest-demo.

This page is static. It makes no network call, keeps no cookie, and records nothing about you.
